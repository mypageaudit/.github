# MyPageAudit GitHub community

Public organization profile and shared contribution, security, issue and pull-request templates. No runtime code, production image or deployment pipeline lives here.

- `profile/README.md`: organization Overview, current Free beta and repo navigation.
- `profile/`: profile logo assets.
- [Profile setup](docs/PROFILE_SETUP.md): description/avatar updates are separate GitHub settings.
- [Contributing](CONTRIBUTING.md), [security reporting](SECURITY.md), `ISSUE_TEMPLATE/` and `PULL_REQUEST_TEMPLATE.md`: shared collaboration entry points.

Engineering ownership/releases live in organization; features/plans live in product; service setup stays with each service. CI checks community files only. Committing profile content does not change remote descriptions, avatars or repository visibility automatically.
