# MyPageAudit organization defaults

Push this directory to the `.github` repository in your organization. `profile/README.md` becomes the public organization profile when this repository is public. The profile contains no application code or secrets. Other repositories inherit default community files where GitHub supports them.

Replace the organization slug in the profile image URL if you choose another name. Keep implementation repositories private until you choose a license and sharing policy.

This directory has its own Git history, version and content-check workflow. It has no runtime Docker image because it contains only organization community files.
