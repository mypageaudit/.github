# Contributing

Start with the owning repository's README. Product features, plans and roadmap belong in product; cross-repository engineering/releases belong in organization. Keep one focused change per pull request, run the documented checks, describe API/data compatibility and add a rollback plan for deployment changes.

Update the canonical owner document instead of copying the same feature history into every README. Runtime logs, screenshots containing personal data, credentials, build outputs and local archives are not source files. Initial application repos remain private until licensing/publication decisions are approved.
